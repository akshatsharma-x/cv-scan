# CV-Scan

CV-Scan is an AI-powered Resume Screener application.

## Overview

This project provides automated resume screening capabilities, utilizing Natural Language Processing (NLP) to evaluate and classify resumes based on extracted text and data.

## Project Structure

- **Resume_Screening_Project/**: Main application directory.
- **dataset/**: Contains datasets used for training and testing the classification models.
- **NLP_Resume_Screening_Report.md**: Detailed report of the NLP techniques and models used.
